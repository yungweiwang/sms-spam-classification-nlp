# Data

This project uses the **SMS Spam Collection** from the UCI Machine Learning Repository.

The dataset contains labeled SMS messages for spam classification research.

## Source

- Dataset: SMS Spam Collection
- Creators: Tiago Almeida and Jos Hidalgo
- Repository: UCI Machine Learning Repository
- DOI: 10.24432/C5CC84
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

## Download

Download the dataset from the UCI Machine Learning Repository and place the file `SMSSpamCollection` in this directory before running the notebook.

The expected project structure is:

```text
data/
└── SMSSpamCollection
